# AkaSide

AkaSide is a psychological horror game inspired by visual novels and classic RPG mechanics.

## Features

- Story-driven gameplay
- Anime-style characters
- Psychological horror atmosphere
- Boss battles
- Multiple endings
- Original soundtrack (planned)
- Apk file (planned)

## Technologies

- Python
- Pygame
